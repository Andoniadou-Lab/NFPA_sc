# NF-PitNET_sc

Code to reproduce the figures and supplementary tables in:

> Kaufman-Cook J, Vamvoukaki R, Kövér B, et al. (2026). A senescence-associated programme marks aggressive non-functioning pituitary neuroendocrine tumours.

## Contents

| File | Description |
|---|---|
| `NFPA_and_healthy_subsetting_from_tumour_atlas.ipynb` | Selection of the 50 samples from the Pituitary Tumour Atlas, producing the integrated object and sample metadata used below (Python, Colab) |
| `Fig1A_sample_overview.R` | Figure 1A: overview of the 50 atlas samples (R) |
| `NFPA_all_figures.py` | Figures 1B-C and 2, the clinical heatmaps and score plots in Figures 3 and 4, Supplementary Figures 1-4, 6 and 7, and Supplementary Table 1 (Python) |

## Data

The single-cell analyses use an integrated AnnData object of 21 NF-PitNETs and 29 healthy pituitary samples (285,907 cells and nuclei) from eight published studies, subset from the Pituitary Tumour Atlas (Kövér et al., in preparation) and available at Zenodo (https://doi.org/10.5281/zenodo.23936955). Accession numbers for every sample are listed in Supplementary Table 1. The tissue figures use Supplementary Table 3 of the paper (`Supplementary_Table_3.xlsx`).

## Running

**Sample selection.** `NFPA_and_healthy_subsetting_from_tumour_atlas.ipynb` documents how the 50 samples were subset from the full Pituitary Tumour Atlas and how the sample metadata table (`nfpa_pituitary_tumor_atlas_2026_10_27.csv`) was generated. It reads the full atlas, which is not yet public; the resulting integrated object is available at Zenodo.

**Fig. 1A.** In R, set `METADATA_CSV` to the atlas sample metadata and run `Fig1A_sample_overview.R`.

**All other figures.** Set `DATA_PATH`, `OUT_DIR` and `SUPP_TABLE3` at the top of `NFPA_all_figures.py`, then paste the script into a single Google Colab cell or run `python NFPA_all_figures.py`. The script runs top to bottom, and each section depends on the sections above it. Missing packages are installed automatically. Figures are written as PDF and PNG (600 dpi), with the underlying tables as CSV. The final section prints the package versions used.

Microscopy panels (Figures 3B-C, 4B and 5; Supplementary Figures 5 and 8) were assembled from images and are not generated by code.
